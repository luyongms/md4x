# md4x v0.1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build md4x v0.1.1 — a Rust CLI that converts a Markdown file to a magazine-quality PDF using bundled JS (mermaid, KaTeX) inside a system WebView, with three bundled templates (`magazine`, `swiss`, `stem`), smart-sizing for mermaid, and copy-as-install deployment on macOS + Windows.

**Architecture:** Single Rust crate, internal module split. `comrak` parses markdown to AST. A small plugin trait dispatches each renderable AST node type to a registered plugin (parser, syntax-highlighter, mermaid, katex). Plugins emit HTML fragments. The orchestrator composes those fragments into a single HTML document with a template's CSS and bundled JS (mermaid, katex, an md4x glue layer that does smart-sizing). The renderer plugin loads the HTML in a system WebView (`wry`) and triggers print-to-PDF via platform-specific APIs (WKWebView's `createPDF` on macOS, WebView2's `PrintToPdfStream` on Windows). All JS / CSS / fonts / template assets are embedded in the binary via `include_dir!` and written to a scratch dir at runtime.

**Tech Stack:** Rust 2024 edition; crates: `clap` (derive, CLI), `anyhow` (errors), `comrak` (markdown parser), `syntect` (syntax highlighting), `wry` + `tao` (cross-platform WebView), `include_dir` (embed bundled assets), `lopdf` (parse output PDFs in tests), `serde` + `serde_json` (diagnostic JSON parsing), `chrono` (date in cover meta), `base64` (data-URL embedding), `tempfile` (scratch dir helper, dev-dep).

**Architectural decisions resolved here (per spec §11):**

1. **Cargo workspace layout** — single crate, internal modules. (Workspace deferred until/unless we need plugin separation for distribution.)
2. **Plugin trait method signatures** — synchronous, returns `Result<String, Error>`. No allocations beyond the returned HTML string.
3. **JS glue ↔ host diagnostic surface** — JS writes structured JSON into a hidden `<div id="md4x-diagnostics">` element via `textContent`. Host calls WebView `evaluate_script` with `document.getElementById('md4x-diagnostics').textContent` after print, parses JSON, prints warnings to stderr.
4. **`comrak` extension set** — `table`, `footnotes`, `strikethrough`, `tasklist`, `autolink`, `tagfilter`, `superscript`. (Citations off; not in v0.1.1.)
5. **Asset locations** — `assets/js/` for bundled JS (mermaid.min.js, katex bundle, md4x-glue.js); `assets/templates/<name>/` for each bundled template. Both embedded via `include_dir!` at compile time.
6. **Renderer integration shape** — single `Renderer` impl with internal `#[cfg(target_os = "macos")]` / `#[cfg(target_os = "windows")]` branches. Linux path is a clear compile-time error.
7. **Bundled template runtime resolution** — `include_dir!` macro embeds all three bundled template directories. At runtime, `--template magazine` looks up the embedded directory's bytes; no temp-dir extraction needed since CSS/HTML/JSON are passed by value into the pipeline.
8. **DOM safety in JS glue** — never use `Element.innerHTML` in our own glue layer. Use `DOMParser` + `Element.replaceChildren()` for SVG replacement so the layer cannot be exploited if a future task accepts user-supplied content.

```rust
use anyhow::Result;
use std::collections::HashMap;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum ContentKind {
    Markdown,
    Code,
    Mermaid,
    Math,
    Renderer,
}

pub trait Plugin: Send + Sync {
    fn handles(&self) -> ContentKind;
    fn transform(&self, source: &str) -> Result<String>;
}

pub struct Registry {
    plugins: HashMap<ContentKind, Vec<Box<dyn Plugin>>>,
}

impl Registry {
    pub fn new() -> Self { Self { plugins: HashMap::new() } }

    /// Register a plugin. If multiple plugins register for the same `ContentKind`,
    /// the **first** registered wins (deterministic).
    pub fn register<P: Plugin + 'static>(&mut self, plugin: P) {
        self.plugins
            .entry(plugin.handles())
            .or_default()
            .push(Box::new(plugin));
    }

    pub fn transform(&self, kind: ContentKind, source: &str) -> Result<String> {
        match self.plugins.get(&kind).and_then(|v| v.first()) {
            Some(p) => p.transform(source),
            None => anyhow::bail!("no plugin registered for {:?}", kind),
        }
    }
}

impl Default for Registry {
    fn default() -> Self { Self::new() }
}
```

```rust
impl Registry {
    pub fn transform_with_diagnostics(
        &self,
        kind: ContentKind,
        source: &str,
        diagnostics: &mut Vec<String>,
    ) -> Option<String> {
        match self.plugins.get(&kind).and_then(|v| v.first()) {
            None => Some(format!("<!-- md4x: no plugin registered for {kind:?} -->")),
            Some(p) => match p.transform(source) {
                Ok(html) => Some(html),
                Err(e) => {
                    diagnostics.push(format!("{kind:?} plugin error: {e}"));
                    Some(format!("<div class=\"md4x-error\">[{kind:?}: error — see diagnostics]</div>"))
                }
            },
        }
    }
}
```

```rust
//! macOS: hidden tao window, wry WebView with our HTML, IPC ready signal,
//! then WKWebView.createPDFWithConfiguration_completionHandler for the PDF
//! and evaluateJavaScript for the diagnostics blob.

use anyhow::Result;
use std::sync::{Arc, Mutex};

pub fn render_to_pdf_macos(html: &str) -> Result<(Vec<u8>, String)> {
    use tao::event::Event;
    use tao::event_loop::{ControlFlow, EventLoopBuilder};
    use tao::window::WindowBuilder;
    use wry::WebViewBuilder;

    let event_loop = EventLoopBuilder::<()>::with_user_event().build();
    let window = WindowBuilder::new()
        .with_visible(false)
        .with_title("md4x renderer")
        .build(&event_loop)?;

    let proxy = event_loop.create_proxy();
    let webview = WebViewBuilder::new(&window)
        .with_html(html)
        .with_ipc_handler(move |req| {
            if req.body() == "md4x-ready" {
                let _ = proxy.send_event(());
            }
        })
        .build()?;

    let result: Arc<Mutex<Option<Result<(Vec<u8>, String)>>>> = Arc::new(Mutex::new(None));
    let r_outer = result.clone();

    use tao::platform::run_return::EventLoopExtRunReturn;
    event_loop.run_return(move |event, _, control_flow| {
        *control_flow = ControlFlow::Wait;
        if let Event::UserEvent(()) = event {
            // Read diagnostics, then export PDF.
            let diag_arc = Arc::new(Mutex::new(String::from("[]")));
            let diag_clone = diag_arc.clone();
            let _ = webview.evaluate_script_with_callback(
                "document.getElementById('md4x-diagnostics')?.textContent || '[]'",
                move |result| {
                    *diag_clone.lock().unwrap() = result;
                },
            );

            // Pump for ~250 ms to let the eval callback fire.
            pump_run_loop(0.25);

            let pdf = export_pdf(&webview);
            let diag = diag_arc.lock().unwrap().clone();
            *r_outer.lock().unwrap() = Some(pdf.map(|b| (b, diag)));
            *control_flow = ControlFlow::Exit;
        }
    });

    result.lock().unwrap().take().unwrap()
}

fn pump_run_loop(seconds: f64) {
    use core_foundation::runloop::{kCFRunLoopDefaultMode, CFRunLoopRunInMode};
    let _ = unsafe { CFRunLoopRunInMode(kCFRunLoopDefaultMode, seconds, 0) };
}

fn export_pdf(webview: &wry::WebView) -> Result<Vec<u8>> {
    use objc2::rc::Retained;
    use objc2::runtime::AnyObject;
    use objc2_foundation::NSData;
    use objc2_web_kit::{WKPDFConfiguration, WKWebView};
    use std::sync::atomic::{AtomicBool, Ordering};

    // SAFETY: wry's macos backend stores the WKWebView pointer; we extract it.
    let wk: &WKWebView = unsafe {
        let raw = webview.as_ref() as *const _ as *const WKWebView;
        &*raw
    };
    let config = unsafe { WKPDFConfiguration::new() };

    let result: Arc<Mutex<Option<Result<Vec<u8>>>>> = Arc::new(Mutex::new(None));
    let done = Arc::new(AtomicBool::new(false));
    let r = result.clone();
    let d = done.clone();

    let block = block2::RcBlock::new(move |data: *mut NSData, err: *mut AnyObject| {
        let value = if !err.is_null() {
            Err(anyhow::anyhow!("createPDF failed (NSError)"))
        } else if data.is_null() {
            Err(anyhow::anyhow!("createPDF returned null data"))
        } else {
            unsafe {
                let d: &NSData = &*data;
                Ok(d.bytes().to_vec())
            }
        };
        *r.lock().unwrap() = Some(value);
        d.store(true, Ordering::SeqCst);
    });

    unsafe { wk.createPDFWithConfiguration_completionHandler(&config, &block); }

    while !done.load(Ordering::SeqCst) {
        pump_run_loop(0.05);
    }

    result.lock().unwrap().take().unwrap()
}
```

```rust
use anyhow::Result;
use chrono::{Datelike, Local};
use std::path::Path;

use crate::plugins::parser::ParserPlugin;
use crate::plugins::Plugin;
use crate::renderer::Renderer;
use crate::templates::Template;

pub struct Pipeline { template: Template }

impl Pipeline {
    pub fn new(template: Template) -> Self { Self { template } }

    pub fn render_md_to_pdf(&self, md_source: &str, input_path: &Path) -> Result<(Vec<u8>, String)> {
        let body = ParserPlugin::new().transform(md_source)?;

        let title = first_h1(md_source).unwrap_or_else(|| {
            input_path.file_stem().map(|s| s.to_string_lossy().into_owned()).unwrap_or_default()
        });
        let subtitle = first_subtitle(md_source);
        let eyebrow = derive_eyebrow(input_path);
        let date = Local::now();
        let date_str = format!("{} {}", month_name(date.month()), date.year());

        let cover = self.template.cover_html
            .replace("{{title}}", &html_escape(&title))
            .replace("{{subtitle}}", &html_escape(&subtitle))
            .replace("{{eyebrow}}", &html_escape(&eyebrow))
            .replace("{{date}}", &date_str);

        let html = format!(
            "<!doctype html>\n<html><head>\n<meta charset=\"utf-8\">\n<title>{title}</title>\n<style>{css}</style>\n</head><body>\n{cover}\n{body}\n<script>window.ipc.postMessage(\"md4x-ready\");</script>\n</body></html>",
            title = html_escape(&title),
            css = self.template.style_css,
            cover = cover,
            body = body,
        );

        Renderer::new().render_html_to_pdf(&html)
    }
}

fn first_h1(md: &str) -> Option<String> {
    md.lines().next().map(|l| l.trim_start_matches('#').trim().to_string()).filter(|s| !s.is_empty())
}

fn first_subtitle(md: &str) -> String {
    let mut lines = md.lines();
    lines.next();
    for line in lines {
        let l = line.trim();
        if l.is_empty() || l.starts_with('#') || l.starts_with("---") { continue; }
        let s = if let Some(rest) = l.strip_prefix("**") {
            if let Some(idx) = rest.find(":**") {
                if !rest[..idx].contains(':') { rest[idx + 3..].trim_start().to_string() } else { l.to_string() }
            } else { l.to_string() }
        } else { l.to_string() };
        return s.replace("**", "");
    }
    String::new()
}

fn derive_eyebrow(p: &Path) -> String {
    p.file_stem().map(|s| s.to_string_lossy().replace('-', " ").to_uppercase()).unwrap_or_default()
}

fn month_name(m: u32) -> &'static str {
    ["JAN","FEB","MAR","APR","MAY","JUN","JUL","AUG","SEP","OCT","NOV","DEC"][(m as usize - 1).min(11)]
}

fn html_escape(s: &str) -> String {
    s.replace('&', "&amp;").replace('<', "&lt;").replace('>', "&gt;")
}
```

```rust
pub struct CodeHighlightPlugin {

    theme: syntect::highlighting::Theme,
}

impl CodeHighlightPlugin {
    pub fn new(theme_name: &str) -> Self {
        let themes = ThemeSet::load_defaults();
        let theme = themes.themes.get(theme_name).cloned()
            .unwrap_or_else(|| themes.themes.values().next().unwrap().clone());
        Self { syntaxes: SyntaxSet::load_defaults_newlines(), theme }
    }
}

impl Plugin for CodeHighlightPlugin {
    fn handles(&self) -> ContentKind { ContentKind::Code }

    /// Source format: "<lang>\n<code>". Returns highlighted <pre>...</pre>.
    fn transform(&self, source: &str) -> Result<String> {
        let (lang, code) = source.split_once('\n').unwrap_or(("", source));
        let lang = lang.trim();
        let syntax = self.syntaxes.find_syntax_by_token(lang)
            .unwrap_or_else(|| self.syntaxes.find_syntax_plain_text());
        Ok(highlighted_html_for_string(code, &self.syntaxes, syntax, &self.theme)?)
    }
}
```

```rust
impl SyntaxHighlighterAdapter for SyntectAdapter {
    fn write_highlighted(&self, output: &mut dyn std::io::Write, lang: Option<&str>, code: &str) -> std::io::Result<()> {
        let main_lang = lang.unwrap_or("").split_whitespace().next().unwrap_or("");
```

```javascript
/* md4x mermaid smart-sizing classification (US-7).
 * Runs after mermaid.run() completes. Walks all rendered SVGs,
 * classifies by effective scale ratio, writes structured JSON
 * into #md4x-diagnostics via textContent for host extraction. */

(function() {
  const PAGE_W = 628;   // A4 portrait, 22mm margins, 96dpi
  const PAGE_H = 951;
  const MIN_READABLE_SCALE = 0.43;
  const MERMAID_DEFAULT_FONTSIZE = 14;

  function classify(naturalW, naturalH) {
    const aspect = naturalW / naturalH;
    let strategy, scale;
    if (aspect > 1.4)        { strategy = "fit-W"; scale = PAGE_W / naturalW; }
    else if (aspect < 0.7)   { strategy = "fit-H"; scale = PAGE_H / naturalH; }
    else                     { strategy = "fit-bounds"; scale = Math.min(PAGE_W / naturalW, PAGE_H / naturalH); }
    const effScale = Math.min(scale, 1.0);
    const textPx = MERMAID_DEFAULT_FONTSIZE * effScale;

    let cls;
    if (effScale >= 0.85)               cls = "fits well";
    else if (effScale >= MIN_READABLE_SCALE) cls = "fits w/ effort";
    else                                cls = "WON'T FIT";

    return { aspect, strategy, scale: effScale, textPx, cls };
  }

  function naturalDims(svg) {
    if (!svg) return null;
    const vb = svg.getAttribute("viewBox");
    if (!vb) return null;
    const parts = vb.trim().split(/\s+/).map(Number);
    if (parts.length !== 4) return null;
    return { w: parts[2], h: parts[3] };
  }

  function emitDiagnostics() {
    const diagnostics = [];
    const blocks = document.querySelectorAll("pre.mermaid, .mermaid");
    blocks.forEach((block, i) => {
      const svg = block.querySelector("svg");
      const dims = naturalDims(svg);
      if (!dims) return;
      const c = classify(dims.w, dims.h);
      diagnostics.push({
        index: i + 1,
        natural_w: dims.w,
        natural_h: dims.h,
        aspect: c.aspect.toFixed(2),
        scale: c.scale.toFixed(2),
        text_px: c.textPx.toFixed(1),
        class: c.cls,
        autofix: block.dataset.md4xAutofix || "",
      });
    });
    let div = document.getElementById("md4x-diagnostics");
    if (!div) {
      div = document.createElement("div");
      div.id = "md4x-diagnostics";
      div.style.display = "none";
      document.body.appendChild(div);
    }
    div.textContent = JSON.stringify(diagnostics);
  }

  // Helper: replace block contents with a parsed SVG, never via innerHTML.
  function replaceWithParsedSvg(block, svgText) {
    const parser = new DOMParser();
    const doc = parser.parseFromString(svgText, "image/svg+xml");
    const newSvgEl = doc.querySelector("svg");
    if (newSvgEl) {
      // Adopt the node into the host document so it is fully usable.
      const adopted = document.adoptNode(newSvgEl);
      block.replaceChildren(adopted);
    }
  }

  window.__md4xSmartSize = async function() {
    if (typeof mermaid === "undefined") { emitDiagnostics(); return; }
    try { await mermaid.run(); } catch (e) {}
    emitDiagnostics();
  };

  // Expose helper for later auto-fix tasks.
  window.__md4xReplaceWithSvg = replaceWithParsedSvg;
})();
```

```javascript
window.__md4xSmartSize = async function() {
  if (typeof mermaid === "undefined") { emitDiagnostics(); return; }
  try { await mermaid.run(); } catch (e) {}

  const blocks = Array.from(document.querySelectorAll("pre.mermaid, .mermaid"));
  for (const block of blocks) {
    const svg = block.querySelector("svg");
    const dims = naturalDims(svg);
    if (!dims) continue;
    const c = classify(dims.w, dims.h);
    if (c.cls !== "WON'T FIT") continue;

    // mermaid replaces the <pre> contents with the SVG. The original source
    // text is preserved on the data-md4x-original attribute we set below
    // OR we read it from the textContent of the original mermaid <pre>
    // (mermaid copies the source text; for this we capture before mermaid runs).
    const orig = block.dataset.md4xOriginal;
    if (!orig) continue;

    let candidate = null;
    if (/^\s*flowchart\s+LR/m.test(orig)) candidate = orig.replace(/(^\s*flowchart\s+)LR/m, "$1TB");
    else if (/^\s*flowchart\s+(TB|TD)/m.test(orig)) candidate = orig.replace(/(^\s*flowchart\s+)(TB|TD)/m, "$1LR");
    if (!candidate) continue;

    const tmpId = "md4x-tmp-" + Math.random().toString(36).slice(2);
    try {
      const { svg: newSvgText } = await mermaid.render(tmpId, candidate);
      // Parse the candidate SVG and measure it.
      const parser = new DOMParser();
      const doc = parser.parseFromString(newSvgText, "image/svg+xml");
      const candidateSvg = doc.querySelector("svg");
      const newDims = naturalDims(candidateSvg);
      if (!newDims) continue;
      const newC = classify(newDims.w, newDims.h);
      if (newC.scale > c.scale) {
        // Adopt and replace, never via innerHTML.
        block.replaceChildren(document.adoptNode(candidateSvg));
        block.dataset.md4xAutofix = "direction-flip";
      }
    } catch (e) { /* keep original */ }
  }

  emitDiagnostics();
};
```
